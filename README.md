# podman

Builds podman and its dependencies (conmon, netavark, aardvark-dns) as real .deb packages for arm64/trixie, published to this repo owner's Forgejo apt package registry.

## Packages

| Image | Description |
|---|---|
| [aardvark-dns](https://github.com/containers/aardvark-dns) | Container-focused DNS server |
| [conmon](https://github.com/containers/conmon) | OCI container runtime monitor |
| [netavark](https://github.com/containers/netavark) | Rust based network stack for containers |
| [podman](https://github.com/podman-container-tools/podman) | Tool to manage containers and pods |
